타사 광고 상품 벤치마킹

벤치마킹 범위: 토스, 배달의 민족, 네이버쇼핑, 캐치테이블, 메타, 네이버 등. 내부 검토 아젠다별 우선순위와 고도화 방향을 정의하고, 카카오 비즈보드·톡 지면에 적용 가능한 상품화 포인트를 정리합니다.

피드형
콘텐츠 연계형 수익화 광고
크리에이터 콘텐츠를 일정 시간 이상 시청한 사용자에게 하단 배너를 자동 노출. 콘텐츠 종료 후 After Video 광고 재생 → 원 콘텐츠 Replay + 배너 유지.

리스트형
오퍼월 광고 → 리스트 광고
클릭을 혜택으로 학습시켜 진입장벽을 낮춤. 최소 비용 리워드로 유입시키고 시청을 "하루 한 번 보너스"로 인지시킴.
채팅탭오퍼월
보상형
미션 수행 리워드
행운복권, 만보기, 버튼 누르기 등 클릭만으로 참여. 둘러보기(최소) → 핵심 기능 사용(중간) → 가입·반복(큰 보상) 단계 학습 구조.
